## Personal-data output minimization

- Do not include raw EUPI, pseudonymous identifiers, or other personal-data
  field values in responses, messages, logs, generated artifacts, or quoted
  tool output.
- Do not modify the source fields; omit their values from output.
- Provide only non-identifying aggregates or links to the authorized source.
- If a request requires individual-level personal data, provide the source
  link instead of reproducing the data.
